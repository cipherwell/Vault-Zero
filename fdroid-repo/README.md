# Self-hosted F-Droid repository (beta channel)

`docs/fdroid/repo/` is a complete F-Droid repository, served by GitHub Pages at

**https://cipherwell.github.io/Vault-Zero/fdroid/repo**

F-Droid, Neo Store and Droid-ify can add that URL as a repository and will then offer updates for
`com.cipherwell.vaultzero` signed by the VaultZero upload key — with no Google account, no Play
Services and no store review.

## Repository signing key

| Item | Value |
| --- | --- |
| Keystore | `~/.cipherwell-release/fdroid-repo.jks` (RSA-4096, PKCS12, alias `vaultzero-repo`) |
| Password | `~/.cipherwell-release/fdroid-repo.env` (`FDROID_REPO_PASS`, 0600) |
| Certificate SHA-256 | `BC:CC:45:55:E6:94:84:E3:14:06:32:BA:07:0E:25:63:95:C9:65:F6:EF:FA:FD:74:06:0B:E7:6A:09:82:F9:49` |

This is the **repository index** key, deliberately separate from the APK upload key. Clients pin it
on first add; if it ever changes, testers must remove and re-add the repository. Back it up with the
upload key (`~/cipherwell-key-backup-*/`).

## Updating for a new release

```bash
# after building/tagging/publishing the APK
scripts/update-fdroid-repo.sh app/build/outputs/apk/release/app-release.apk 1.7.1 10
git add docs/fdroid/repo fdroid-repo/metadata/com.cipherwell.vaultzero.yml
git commit -m "fdroid repo: publish v1.7.1"
git push
```

The script rebuilds the signed index with `fdroidserver`, prunes older APKs from the repo, copies the
result into `docs/fdroid/repo/`, and prints the repo URL + fingerprint. Bump
`CurrentVersion`/`CurrentVersionCode` in `fdroid-repo/metadata/com.cipherwell.vaultzero.yml` when the
version changes (the script copies that file into the working directory).

Working directory (not committed): `~/.local/share/vaultzero-fdroid`, generated by the script.
`fdroidserver` venv: `~/.local/venvs/fdroid` (`pip install fdroidserver`).

## Adding the repo on a device

1. Install F-Droid (or Neo Store / Droid-ify) from its own website.
2. Settings → Repositories → Add repository → `https://cipherwell.github.io/Vault-Zero/fdroid/repo`
3. Confirm the fingerprint `BC:CC:45:55:…:F9:49`.
4. Search for VaultZero and install/update from there.

## Notes / limitations

- The app icon in the client list falls back to a generic icon: the release APK obfuscates resource
  names (R8 resource shrinking), so `fdroidserver` cannot extract `ic_launcher` from it. Cosmetic only.
- Only the **current** APK is kept in the repo to keep the Pages site small; older builds remain on
  GitHub Releases.
- GitHub Pages serves these files; no tracking or Google infrastructure is involved.
