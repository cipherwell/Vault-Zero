VaultZero is an offline, zero-knowledge password manager and encrypted vault for Android. No account, no network permission, no telemetry: your vault never leaves the device except in encrypted backups you explicitly export.

VAULT
• Logins with live RFC 6238 TOTP codes, payment cards, API keys, crypto wallets and seed phrases, secure notes, and identity documents.
• Record titles, categories and tags are encrypted inside each record; raw database columns and backups contain only redacted placeholders.
• AES-256-GCM per-record encryption with Additional Authenticated Data binding, so swapped or tampered rows fail closed and are never displayed.
• A random 256-bit vault key is wrapped independently by your master password and a BIP-39 12-word recovery phrase (2048-word standard, 128-bit entropy) using Argon2id (64 MiB memory, 3 iterations). Vaults created by older versions still open and are upgraded transparently. Recovery kits can be rotated without changing the vault.

SECURITY
• No INTERNET or network-state permission — the app cannot connect anywhere.
• FLAG_SECURE blocks screenshots and recent-apps previews; sensitive clipboard entries are flagged and cleared.
• Hardware-backed biometric unlock with Android Keystore and BiometricPrompt.CryptoObject (per-use authentication), prompted automatically on launch when enabled.
• Configurable auto-lock, background lock and clipboard timeouts, master-password rotation, and a local security audit.

BACKUPS
• Versioned AES-256-GCM envelope written through the system file picker (no cloud integration).
• Restore with the source master password or 12-word recovery phrase; optional phrase-only export.
• Verified imports: duplicate-safe merges, in-place updates, and an explicit option to salvage readable records from a damaged file.
• Phone-to-phone migration: a fresh install can restore a full backup with your existing 12-word recovery kit — no new seed phrase — while keeping the original master password (or setting a new one).

EXTRAS
• Password and passphrase generator (session history held in memory only), live 2FA dashboard, audit-backed search (is:weak, is:reused, is:stale, is:no2fa), undo delete, recently-used sort, launcher shortcuts, and light/dark/system appearance with an One UI-inspired design.
