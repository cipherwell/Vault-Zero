# VaultZero — UI style audit (2026-11-22)

Scope: every reachable screen in v1.7.17/1.7.18, light + dark, English + Spanish, on a
1080 × 2400 / 411 dp device (Pixel-class), plus narrow-screen and large-font checks.

## Method
1. Seeded the production-style vault with the instrumentation fixture
   (`VaultSetupDeviceTest`: logins, weak/reused passwords, 2FA, card, note, API secret, wallet, identity).
2. Captured and reviewed: setup, lock, recovery kit, vault (populated + filters + search),
   item detail, add-item sheet, generator, audit, settings (top/bottom, danger zone), reset dialog,
   language dialog, dark theme, Spanish, narrow width, large font.
3. Checked against the design tokens: 8 dp spacing rhythm, 12/16/20/26 dp radii, blue primary,
   emerald success, amber warning, red danger; 48 dp touch targets; text contrast in both themes.

## Findings fixed
| Area | Issue | Fix |
| --- | --- | --- |
| Recovery kit (ES) | Confirm button fixed at 48 dp clipped “Abrir bóveda” | `heightIn(min = 48 dp)`, 2-line wrap, centred text |
| Recovery grid | Long words broke mid-word on narrow/large-font screens | 3 columns kept; word size derived from cell width + `fontScale`; single line; even 6 dp spacing |
| Vault filters | Last chips cut off at the screen edge | FlowRow wrapping into 2 rows + compact labels in both languages |
| Vault / audit lists | Last card sat under the bottom navigation | 110 dp bottom content padding |
| 2FA row | Code and timer visually merged | “·” separator between code and countdown |
| Lock screen | No escape when both credentials are lost | Subtle **Reset vault** link + destructive confirmation dialog |
| Generated password | Could be dismissed without saving | Mandatory “I saved this password” checkbox + persistent amber banner |

## Verified good
- Light/dark parity: cards, chips, inputs and nav use the same tokens; no hard-coded colours.
- Typography hierarchy: display title → section label → body → caption; no truncation in EN/ES at 411 dp.
- Destructive actions (delete item, reset vault, danger zone) are consistently red and always confirmed.
- Touch targets ≥ 48 dp; search, filters and FAB reachable one-handed.
- Spanish copy fits after the chip/button fixes; setup, recovery, settings and audit reviewed.

## Known limitations (accepted)
- The reset flow intentionally requires no password (it is the last resort); it is destructive and
  double-confirmed, and it cannot recover data — by design.
- Filter chips now take two rows on phones; this is deliberate so every type is visible without a
  hidden horizontal scroll.
- Screenshots of the shipped build are blocked by `FLAG_SECURE`; audit images were captured from the
  screenshot-enabled debug build seeded with fictional data.
