VaultZero

An encrypted password manager and cryptographic vault for Android that cannot reach the internet. No account, no telemetry, no cloud — just hardware-backed encryption and encrypted backups you control.

Download the APK View source Documentation

Networkless by design

No INTERNET permission and no networking code. Your vault cannot leave the device unless you export a backup.

Hardware biometrics

Per-use Keystore keys gated by BiometricPrompt with CryptoObject; the prompt appears automatically when enabled.

Verified backups

AES-256-GCM envelopes openable with the master password or 12-word recovery phrase, with duplicate-safe imports.

New phone migration

Restore a full backup at first run with your existing 12-word kit — no new seed phrase — and keep the original master password for standard backups.

Local-only audit

Weak/reused/stale passwords and 2FA issues are found on-device. Nothing is uploaded.

Security model

AES-256-GCM per record, Argon2id (64 MiB, t=3) for the password and recovery envelopes (legacy PBKDF2 vaults migrate transparently), a random 256-bit vault key wrapped by both your master password and your checksummed 12-word recovery phrase, FLAG_SECURE, and no cloud/backup APIs. See the security documentation.
