and F-Droid can offer every new beta version without GitHub or Google Play.

   https://cipherwell.github.io/Vault-Zero/fdroid/repo

## Notes
- The one-tap link only works after F-Droid is installed. On desktop it opens a page with the same
  instructions.
- Neo Store and Droid-ify accept the same repository URL.
- Installing the APK directly from GitHub Releases works, but does **not** auto-update; use Obtainium
  with `https://github.com/cipherwell/Vault-Zero` for that route.
- This is the beta channel; the repository is signed by the project’s repo key. Verify the fingerprint
  above before trusting it.
