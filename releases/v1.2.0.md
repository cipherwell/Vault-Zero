## ✨ New: move to a new phone without a new seed phrase

A fresh install now offers **Restore from Backup** on the first-run screen:

1. Choose the encrypted `.json` backup exported by the old phone.
2. Enter the old phone's **12-word recovery phrase**.
3. Optional for standard backups: set a new master password for this device. Leave blank to keep
   the original; phrase-only backups require a new password.
4. VaultZero verifies the envelope and **every record** before writing, then opens the restored
   vault.

Guarantees:

- The restored vault keeps the **same recovery phrase and key fingerprint** — no second seed
  phrase is generated.
- Standard backups keep the **original master password** unless you choose a new one.
- Favourites, timestamps and last-used values are preserved; ciphertext is installed as-is.
- The restore refuses to overwrite an existing vault. Once a new vault is created or a backup is
  restored, the restore option disappears from the lock/setup screen; merging into an existing
  vault continues to use **Settings → Restore / Import Encrypted Backup**.
- Nothing is written on a wrong phrase, tampered record, unsupported KDF parameters or malformed
  envelope. Biometrics are device-local, so re-enable them after migration.
