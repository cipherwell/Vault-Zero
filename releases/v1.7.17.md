# 🛡️ VaultZero `v1.7.17` — Spanish recovery-screen fixes

**Release date:** 22 November 2026
**Package:** `com.cipherwell.vaultzero` · **versionCode:** 26
**Min SDK:** 24 · **Target/compile SDK:** 36 · **License:** MIT

Two layout bugs on the recovery-kit screen, reported from the Spanish build.

## Fixed

- **The confirm button no longer clips.** The Spanish label
  “Ya guardé mi kit de recuperación — Abrir bóveda” wrapped to two lines while the button was fixed at
  48 dp, cutting off “Abrir bóveda”. The button now grows with the label, centres up to two lines and
  keeps the full text.
- **The 12-word grid keeps words intact.** On narrower screens or larger system fonts, long words
  could break mid-word (“together” → “togethe” + “r”). The grid keeps **three columns**, sizes each
  word to its cell (accounting for the system font scale) and keeps it on one line, with even spacing.

## Verification

- **137 JVM/Robolectric tests / 0 failures**, lint 0 errors.
- Captured both languages on the API 34 emulator: Spanish button fully visible at one and two lines;
  grid aligned with words intact; English unchanged.
