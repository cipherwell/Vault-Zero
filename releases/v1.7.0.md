# 🛡️ VaultZero `v1.7.0` — English / Spanish, end to end

**Release date:** 21 November 2026
**Package:** `com.cipherwell.vaultzero` · **versionCode:** 9
**Min SDK:** 24 (Android 7.0) · **Target/compile SDK:** 36 · **License:** MIT
**Source:** https://github.com/cipherwell/Vault-Zero
**Website:** https://cipherwell.github.io/Vault-Zero/

VaultZero is now fully bilingual: **English (US)** and **Spanish (US)**. Every screen, dialog,
empty state, accessibility description, status message and validation error is translated — 477
strings and 19 plurals per language, with catalog parity enforced by tests.

## 🌎 Language switching

- **On the lock / setup screen.** A first-time user can switch language before creating a vault, so
  the very first screen (master password setup, restore-from-backup, recovery kit) is readable from
  the start. The toggle labels the target language in that language ("Español (US)" / "English (US)").
- **In Settings.** Choose System / English (US) / Español (US) at any time. The switch is applied
  through a localized composition, so it takes effect **instantly and without recreating the
  activity** — an unlocked vault stays unlocked.
- **Persisted outside the vault.** The selection survives app restarts and "Reset vault", and
  Android 13+ lists the app in the system per-app language picker (`android:localeConfig`).

## ✅ Verification

- **128 JVM/Robolectric tests / 0 failures** (+9 over 1.6.0), including two new guards:
  `LocalizationCatalogTest` (EN/ES key + placeholder parity, duplicate-key detection, translation
  ratio) and `LanguageControllerTest` (system default, persistence, fallback).
- **On-device (API 34):** `LanguageDeviceTest` proves the Spanish resources ship inside the APK,
  that every string id resolves in both languages, and that the selection is stored outside the
  vault preferences.
- **Live QA:** fresh install → Spanish setup screen → vault created in Spanish → Settings →
  instant switch back to English while unlocked → force-stop/relaunch keeps the selection.
  Screenshots: [`docs/screenshots`](https://github.com/cipherwell/Vault-Zero/tree/main/docs/screenshots).
- Lint: 0 errors. 477/477 string keys and 19/19 plurals present in both catalogs.

## 🔐 Security

Unchanged from 1.6.0: Argon2id (64 MiB, t=3) password/recovery envelopes, AES-256-GCM records with
AAD binding, BIP-39 128-bit recovery kits, verified encrypted backups, hardware biometrics, no
network permission, no telemetry. Localization adds no storage or network surface; data-layer
failures now carry a typed error code so messages can be translated without changing behavior.
