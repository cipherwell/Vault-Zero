# 🛡️ VaultZero `v1.7.16` — biometric onboarding & safer generated passwords

**Release date:** 22 November 2026
**Package:** `com.cipherwell.vaultzero` · **versionCode:** 25
**Min SDK:** 24 · **Target/compile SDK:** 36 · **License:** MIT

Three onboarding improvements requested for the beta.

## What's new

- **Biometric unlock during vault creation.** A switch on the setup screen enables it. After you save
  the recovery kit and open the vault, the system biometric prompt wraps the vault key immediately.
  If the phone has no fingerprint/face enrolled, the switch is disabled with a clear hint.
- **Automatic biometric prompt on every open.** With biometrics enabled, the prompt appears when the
  app is opened, when it comes back from the background, and after an auto-lock — no extra tap.
- **Stronger warning for generated master passwords.** The generated-password dialog now requires
  ticking **“I saved this password in a safe place”** before it can be dismissed, and an amber
  reminder stays on the setup screen until the vault is created.
