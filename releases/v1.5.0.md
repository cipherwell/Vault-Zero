This release moves VaultZero to its final Cipherwell Android package ID and requires a data migration
because the old package (`com.aistudio.vaultzero.secvlt`) is a different app identity.

## ⚠️ Migration from v1.4.0 or earlier

1. In the old app: **Settings → Export Encrypted Vault Backup** (standard or phrase-only).
2. Save the 12-word recovery phrase / master password.
3. Install `com.cipherwell.vaultzero` v1.5.0 (it can coexist with the old package).
4. On first run choose **Restore from Backup**, select the backup and enter its recovery phrase.
5. After verifying the vault, uninstall the old package.

The new package uses the same Cipherwell signing key; future updates continue normally.

## 🔐 Security

Same hardened app as v1.4.0: AES-256-GCM record encryption with AAD binding, PBKDF2-HMAC-SHA256
600k, BIP-39 128-bit recovery kits, hardware per-use biometrics, first-run restore, verified
encrypted backups, no network permission and no telemetry. Audit:
[`docs/AUDIT-2026-11-15-recovery-and-encryption.md`](https://github.com/cipherwell/Vault-Zero/blob/main/docs/AUDIT-2026-11-15-recovery-and-encryption.md).
