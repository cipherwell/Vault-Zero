# 🛡️ VaultZero `v1.7.1` — beta-readiness release

**Release date:** 21 November 2026
**Package:** `com.cipherwell.vaultzero` · **versionCode:** 10
**Min SDK:** 24 (Android 7.0) · **Target/compile SDK:** 36 · **License:** MIT
**Source:** https://github.com/cipherwell/Vault-Zero
**Beta guide:** https://github.com/cipherwell/Vault-Zero/blob/main/docs/BETA.md

Small release aimed at making a **soft beta** possible: testers now have a privacy-safe way to report
problems, and the UI no longer uses iOS branding for Android biometrics.

## What changed

- **Settings → About → Copy diagnostics.** Produces a short, fixed-format block: app version/build,
  package, Android release/API, device manufacturer/model, selected language, vault state and item
  count, biometric state, key fingerprint and the last error. It **never** includes record titles,
  usernames, passwords, recovery phrases or key material, and it is only generated when the button
  is tapped — there is still no telemetry, no analytics and no network permission.
- **Android biometric wording:** “Touch ID / Biometrics” → **“Fingerprint / Biometrics”**
  (“Huella digital / Biometría”).
- **Beta materials** in the repo: `docs/BETA.md` (tester guide, verification steps, known limits),
  `docs/SOCIAL-BETA-POST.md` (EN/ES announcement drafts, pinned-comment template) and
  `docs/PLAY-INTERNAL-TESTING.md` (maintainer checklist).

## Verification

- **131 JVM/Robolectric tests / 0 failures** (+3 for the diagnostics builder, which asserts the
  report contains build/device fields and nothing optional is invented).
- Lint: 0 errors.
- Release APK: `versionCode 10`, Cipherwell certificate, v2-signed, no network permissions.

## Still true for this beta

Pre-audit software: self-audited and self-pentested only. Use **test secrets only**, keep the
12-word recovery kit on paper, and don't migrate your only real vault yet. No auto-update on
sideloaded builds — install each release manually (Play internal testing is documented but not
live).
