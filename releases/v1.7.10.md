# 🛡️ VaultZero `v1.7.10` — Spanish biometric layout fix

**Release date:** 21 November 2026
**Package:** `com.cipherwell.vaultzero` · **versionCode:** 19
**Min SDK:** 24 · **Target/compile SDK:** 36 · **License:** MIT

The Spanish biometric settings row no longer clips. Measured on the API 34 emulator in `es-US`:

| | before | after |
| --- | --- | --- |
| Biometric switch right edge | **1048 px** (screen 1080, content ends 1027) | **985 px** |
| Description width | pushed the switch out | wraps to 2 lines, ends at 816 px |
| Lock-screen label | `Huella digital / Biometría (desactivada)` (40 chars) | `Huella / Biometría (desactivada)` (33) |

## What changed

- **Settings biometric row:** the icon + text block is now `weight(1f)` and its column is weighted
  too, with `maxLines = 2` + ellipsis. The switch can no longer be pushed outside the card in any
  locale or font scale.
- **Lock-screen biometric button:** `heightIn(min = 48.dp)` instead of a fixed 48 dp, `maxLines = 1`
  with centred ellipsis, and the text takes only the remaining width.
- **Shorter Spanish labels** for the lock-screen button, with margin to spare.
- English layout verified unchanged (switch at 985 px, text at its natural width).

## Verification

- **131 JVM/Robolectric tests / 0 failures**, lint 0 errors.
- Signed build installed on the API 34 emulator; UI inspected with `uiautomator` bounds in **es-US**
  and **en-US** (screenshots are blocked by the app's `FLAG_SECURE`, by design).
- No functional or cryptographic changes.
