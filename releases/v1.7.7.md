# 🛡️ VaultZero `v1.7.7` — realistic key proportions

**Release date:** 21 November 2026
**Package:** `com.cipherwell.vaultzero` · **versionCode:** 16
**Min SDK:** 24 · **Target/compile SDK:** 36 · **License:** MIT

The key now has believable proportions instead of a squat pictogram. Same identity — V bow, Z bit,
cyan V, sparkle, flat depth — rebuilt to a real key's ratios.

## What changed

- **Longer shaft, smaller bow.** Bow Ø 23 against a 23-unit shaft and a 16 × 18 bit (was a 32 × 13.5
  stripe), so the silhouette reads as a key at 48 dp.
- **The Z is taller than wide** (16 × 18, 5.5 stroke), matching a real capital Z and a real key bit.
- **Everything inside the 66 dp safe circle** (glyph scaled 0.95); verified with a safe-circle overlay
  and a fresh launcher capture.
- Adaptive layers, separate monochrome layer (V stays a hole), legacy squircle/round PNGs, 512 px
  icon and feature graphic regenerated from `design/icon/make_icon.py`.

## Verification

- **131 JVM/Robolectric tests / 0 failures**, lint 0 errors (no functional changes).
- Signed 1.7.7 installed on the API 34 emulator and rendered under the circular launcher mask with no
  clipping.
