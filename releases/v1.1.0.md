repository and must never be trusted for updates.

## ✨ What's new since the preview

**Design & usability**
- Samsung One UI-inspired design language with light, dark and system appearance.
- Live **2FA dashboard**, copy-2FA from the list, audit-backed search filters
  (`is:weak`, `is:reused`, `is:stale`, `is:no2fa`, `is:clean`).
- Undo delete, recently-used sort, bulk favourite, launcher shortcuts
  (New login / Generator), and empty-state quick actions.
- Passphrase options (separator and capitalisation), backup progress feedback,
  import result summaries and export previews.
- Editor protects unsaved edits; revealed secrets re-mask after 15 s.

**Security**
- PBKDF2-HMAC-SHA256 increased to **600,000 iterations** (preview file compatible;
  legacy vaults transparently upgrade on unlock).
- Hardware **per-use** biometric wrapping of the vault key
  (`BiometricPrompt.CryptoObject`), automatically shown on launch when enabled.
- Configurable **background locking** (screen-off locks immediately; SAF picker
  exempt), and auto-lock/clipboard options including explicit Off.
- **Change Master Password** without re-encrypting records; recovery kit stays valid.
- Verified backup imports: duplicate-safe merges, in-place updates, atomic writes,
  optional phrase-only exports, and explicit salvage of readable records.
- Backup import hardened against hostile KDF iteration counts / oversized salts
  and envelopes.
- Pentest report: [`docs/PENTEST-2026-11-15.md`](../docs/PENTEST-2026-11-15.md).

**Crypto parameters (unchanged core)**
- Random 256-bit vault master key (VMK); per-record AES-256-GCM.
- AAD binds each record to `VaultZero_Record_v2:<id>:<type>`, rejecting row swaps.
- VMK wrapped independently by the password KEK and the checksummed 12-word
  recovery phrase KEK (PBKDF2-HMAC-SHA256, 600,000 iterations, 128-bit salts).
- Titles/categories/tags live inside the encrypted record envelope; SQLite and
  backup JSON carry redacted placeholders.

build contains no app data; `run-as` and screenshot capture are blocked.
