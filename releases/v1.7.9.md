# 🛡️ VaultZero `v1.7.9` — Samsung-soft key

**Release date:** 21 November 2026
**Package:** `com.cipherwell.vaultzero` · **versionCode:** 18
**Min SDK:** 24 · **Target/compile SDK:** 36 · **License:** MIT

The key icon now follows Samsung's One UI icon language instead of an illustrated sticker: a matte
squircle with a vertical gradient, one white glyph, a **diffuse shadow**, and no extra decoration.

## What changed

- **Sparkles removed.** Nothing competes with the key.
- **Soft shadow instead of a hard offset:** the shadow is a pre-blurred 432 px bitmap (σ 2.6) layered
  under the vector key, so it stays diffuse at every density.
- **Vertical gradient background** (`#5C8DFF → #2F6BFF → #1A44C4`) with a white wash from the top —
  the matte look Samsung uses on its own apps.
- **Cleaner lines:** the V is a background-coloured cutout (no cyan fill), stroked with a matching
  patch so the shadow cannot bleed into the hole and muddy it.
- **Smaller Z:** the bit is now 13 × 14 with a 5.5 stroke (was 16 × 18 / 7), so it sits in proportion
  with the Ø 23 bow and the shaft.

## Verification

- **131 JVM/Robolectric tests / 0 failures**, lint 0 errors (no functional changes).
- Signed 1.7.9 installed on the API 34 emulator and rendered under the circular launcher mask: clean
  V cutout, soft shadow, no clipping.
- Adaptive layers, separate monochrome layer, legacy squircle/round PNGs, 512 px icon and feature
  graphic regenerated from `design/icon/make_icon.py`.
