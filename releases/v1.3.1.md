## 🔧 Changes for distro builders

- Release builds are **unsigned when `KEYSTORE_PATH`/`STORE_PASSWORD`/`KEY_PASSWORD` are absent**
  (F-Droid build server, community builders). Distributors sign the APK with their own key.
- Production-signed local/CI builds still work unchanged when the environment is set.
- `compileSdk` is plain **36** (target 36) to avoid requiring the 36.1 minor SDK on build servers.
- F-Droid recipe added/cleaned in `fdroid/com.aistudio.vaultzero.secvlt.yml`:
  current version 1.3.1 / versionCode 5, tag `v1.3.1`, no unnecessary `subdir`, no debug-keystore
  scan entry.
- Fastlane short description no longer ends with a period (F-Droid metadata rule).

## 🔐 Security (same as 1.3.0)

BIP-39 128-bit recovery kits with unique words, legacy compatibility, recovery-kit rotation,
AES-256-GCM records/AAD, PBKDF2 600k, verified backups. Full audit:
[`docs/AUDIT-2026-11-15-recovery-and-encryption.md`](https://github.com/cipherwell/Vault-Zero/blob/main/docs/AUDIT-2026-11-15-recovery-and-encryption.md).

**Signature note for F-Droid users:** F-Droid will sign its build with the F-Droid key, so it cannot
update an installation signed with this GitHub key (and vice versa). Choose one distribution channel
per device; encrypted backups and the recovery phrase move the vault between them.

## ⬆️ Upgrade notes

- In-place from 1.3.0 (same production key, versionCode 5).
- F-Droid first-time installers get the F-Droid-signed build once included.
