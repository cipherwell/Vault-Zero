Documentation release: a complete, plain-language guide in **English and Spanish**, plus a correction

The guide covers every feature in plain language (all six record types, search/filters, generator,
2FA codes, security audit, every Settings row, recovery kit, biometrics, backups and migration), how
the security works, an honest comparison with cloud password managers, what the app cannot protect
against, and the pre-beta audit summary.

## Fixed

- **In-app cryptographic specifications** in Settings still described PBKDF2 600,000 rounds as the
  current KDF. It now states **Argon2id (64 MiB, t=3, p=1)** with PBKDF2 labelled as the legacy
  envelope format, plus per-record AAD binding and the BIP-39 recovery phrase. Both languages updated.
