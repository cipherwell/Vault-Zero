# 🛡️ VaultZero `v1.7.18` — lock-screen reset + UI audit

**Release date:** 22 November 2026
**Package:** `com.cipherwell.vaultzero` · **versionCode:** 27
**Min SDK:** 24 · **Target/compile SDK:** 36 · **License:** MIT

A last-resort reset path, plus the fixes from a full visual pass over the app.

## What's new

- **Reset vault from the lock screen.** A deliberately low-emphasis “Reset vault” link under
  “Forgot Master Password?” opens a red destructive confirmation: every record, key and biometric
  enrolment is erased permanently. It is only for the case where **both** the Master Password and the
  12-word Recovery Kit are lost; the dialog says so explicitly and the vault cannot be recovered
  afterwards.
- Verified end-to-end: erase → setup screen, language/theme retained, no records remain.

## UI audit fixes

- **Filter chips wrap into two even rows** instead of scrolling off the screen; compact labels in both
  languages (Logins/Cards/APIs/Wallets/Notes/IDs · Accesos/Tarjetas/APIs/Billeteras/Notas/IDs).
- **Bottom padding** on the vault and audit lists so the last row/card clears the navigation bar.
- **2FA row** separates the code and countdown with “·”.
- Full report: [`docs/design/UI-AUDIT-2026-11-22.md`](https://github.com/cipherwell/Vault-Zero/blob/main/docs/design/UI-AUDIT-2026-11-22.md).

## Verification

- **137 JVM/Robolectric tests / 0 failures**, lint 0 errors.
- The BIP-39 tamper test was made deterministic (the old one could pass a wrong word 1/16 of the time).
- Audited light/dark, English/Spanish, narrow width and large fonts on the seeded debug build; reset
  tested on the API 34 emulator.
- Shipped APK: `versionCode 27`, `flags=0x0`, `screencap` 0 bytes.
