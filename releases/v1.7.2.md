# 🛡️ VaultZero `v1.7.2` — new icon, proper adaptive layers

**Release date:** 21 November 2026
**Package:** `com.cipherwell.vaultzero` · **versionCode:** 11
**Min SDK:** 24 (Android 7.0) · **Target/compile SDK:** 36 · **License:** MIT
**Source:** https://github.com/cipherwell/Vault-Zero
**Beta guide:** https://github.com/cipherwell/Vault-Zero/blob/main/docs/BETA.md

A visual release: VaultZero gets a proper launcher icon that works with **any launcher mask, icon
pack and Android 13+ themed icons**.

## The mark

A **zero-shaped keyhole** — a fitted ring (the zero of zero-knowledge) merged into a rounded stem.
Vector geometry, no lettering, no baked-in mask, so it stays crisp from 24 px to 512 px.

- **Adaptive layers:** full-bleed gradient background (`#2F6BFF → #0A2366`) + foreground glyph kept
  inside Android's 66 dp safe circle — circle, squircle, rounded-square, teardrop and OEM masks
  never clip it.
- **Monochrome layer:** a separate single-colour silhouette for themed icons. The previous icon
  reused the coloured artwork as its monochrome mask, which rendered as a filled squircle.
- **Legacy fallbacks:** squircle and round PNGs at mdpi–xxxhdpi for launchers and icon packs that
  ignore adaptive icons.
- **Matching artwork:** 512 px store icon, rebuilt 1024 × 500 feature graphic, F-Droid repository
  icon, and a source package in `design/icon/` (geometry script + SVGs + preview sheet) so the mark
  can be regenerated deterministically.

## Verification

- **131 JVM/Robolectric tests / 0 failures**, lint 0 errors (no functional changes).
- Icon rendered on the API 34 emulator launcher under its circular mask, and the monochrome layer
  was exercised by the launcher's themed-icon path.
- Preview sheet: `design/icon/icon-preview-sheet.png` (masks, density ladder, dark/light,
  monochrome, store icon).

## Upgrade

Installs over 1.7.1 (same signing key). The new icon appears after the launcher refreshes its icon
cache — force-stopping the launcher or reinstalling… which is exactly what installing this build
does.
