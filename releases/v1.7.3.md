# 🛡️ VaultZero `v1.7.3` — the zero holds a fingerprint

**Release date:** 21 November 2026
**Package:** `com.cipherwell.vaultzero` · **versionCode:** 12
**Min SDK:** 24 (Android 7.0) · **Target/compile SDK:** 36 · **License:** MIT
**Source:** https://github.com/cipherwell/Vault-Zero
**Beta guide:** https://github.com/cipherwell/Vault-Zero/blob/main/docs/BETA.md

The icon is now a **zero holding a fingerprint**: the ring is the zero (zero-knowledge, and the
vault door), the whorl inside — two ridges plus a core, gaps aligned on a lower-left delta — is
biometrics. Same construction as 1.7.2, so it still fits every launcher.

## What changed

- **Launcher mark**: closed zero ring + fingerprint whorl, white on the `#2F6BFF → #0A2366`
  gradient. Glyph stays inside Android's 66 dp safe circle.
- **Monochrome layer**: the whorl silhouette, so Android 13+ themed icons tint correctly.
- **Legacy renders**: squircle and round PNGs at mdpi–xxxhdpi regenerated from the same vector
  source; 512 px store icon and the 1024 × 500 feature graphic rebuilt.
- **Name lockup**: `design/icon/vaultzero-icon-lockup.svg` (mark + `VAULTZERO`) for store and social
  artwork. The name is deliberately **not** drawn inside the adaptive icon: text at launcher size is
  unreadable and would break the safe zone. The feature graphic and release artwork carry it.

## Verification

- **131 JVM/Robolectric tests / 0 failures**, lint 0 errors (no functional changes).
- Signed 1.7.3 installed on the API 34 emulator and rendered under Pixel launcher's circular mask;
  the monochrome layer is present in the packaged adaptive icon.
- Preview sheet: `design/icon/icon-preview-sheet.png` (density ladder, dark/light, masks,
  monochrome, lockup, 512 icon).
