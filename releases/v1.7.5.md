# 🛡️ VaultZero `v1.7.5` — the key is the initials

**Release date:** 21 November 2026
**Package:** `com.cipherwell.vaultzero` · **versionCode:** 14
**Min SDK:** 24 (Android 7.0) · **Target/compile SDK:** 36 · **License:** MIT

The icon is now a **key that carries the initials**: the bow — the part you hold — is a loop with a
**V-shaped opening**, and the bit/tip is a **Z**. One silhouette, no lettering, readable as a key at
48 dp and as V + Z up close.

## Implementation

- Adaptive layers: full-bleed `#2F6BFF → #0A2366` gradient; white key foreground (even-odd bow with
  V hole, 9 dp shaft, 7 dp Z bit) kept inside the 66 dp safe circle.
- Separate **monochrome layer** for Android 13+ themed icons.
- Legacy squircle/round PNGs at mdpi–xxxhdpi, regenerated 512 px store icon and 1024 × 500 feature
  graphic, F-Droid repository icon.
- Source + preview sheet: `design/icon/`.

## Verification

- **131 JVM/Robolectric tests / 0 failures**, lint 0 errors (no functional changes).
- Signed 1.7.5 installed on the API 34 emulator and rendered under the circular launcher mask.
- Monochrome layer present in the packaged adaptive icon; legacy and store assets generated from the
  same vector source.
