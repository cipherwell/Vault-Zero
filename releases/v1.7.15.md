# 🛡️ VaultZero `v1.7.15` — generate a master password at setup

**Release date:** 22 November 2026
**Package:** `com.cipherwell.vaultzero` · **versionCode:** 24
**Min SDK:** 24 · **Target/compile SDK:** 36 · **License:** MIT

New users no longer have to invent a strong master password from scratch.

## What's new

- **Sparkle button inside the Master Password field** on the setup screen. It generates a
  **20-character** password with the device's CSPRNG (mixed case, digits, symbols, no look-alikes),
  fills both password fields, reveals it, and opens a **save-it-now dialog**.
- The dialog shows the password, a **Copy** button, and the warning that the 12-word Recovery Kit is
  the only way back. Tapping **I saved it** hides the fields again.
- Fully localized in English and Spanish; no cryptographic changes (the generated password derives
  the key exactly like a typed one).
