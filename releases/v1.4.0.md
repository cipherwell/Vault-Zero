**Release date:** 15 November 2026

**Min SDK:** 24 (Android 7.0) · **Target/compile SDK:** 36 · **License:** MIT

This release introduces the **Cipherwell** project identity and a new production signing key.
Functionally it is the same app as 1.3.1 (BIP-39 recovery kits, first-run restore, hardware
biometrics, offline vault).

## ⚠️ Signing identity and upgrade

`v1.4.0` is signed with a **new production key** (`CN=Cipherwell`). It cannot update an install
signed by the earlier key in place — Android will report a signature mismatch.

- Export an encrypted backup + recovery phrase before switching.
- Uninstall the old app, install v1.4.0, restore the backup.
- F-Droid will sign its own builds independently when the app is eventually included.

## 🔐 Security and features

- BIP-39 128-bit recovery kits with unique words; legacy kit compatibility; recovery-kit rotation.
- AES-256-GCM records with AAD binding, PBKDF2-HMAC-SHA256 600k, hardware per-use biometric unlock.
- First-run restore from an encrypted backup using the existing recovery phrase.
- Verified, duplicate-safe backup import; SAF-only, no network permission, no telemetry.
- 105 JVM/Robolectric tests, 0 failures; lint clean; signed release built locally and verified.
- Audit: [`docs/AUDIT-2026-11-15-recovery-and-encryption.md`](https://github.com/cipherwell/Vault-Zero/blob/main/docs/AUDIT-2026-11-15-recovery-and-encryption.md)
